# /learn-pass — Agent Self-Learning Pass

Use after meaningful work to extract reusable lessons without polluting active memory.

Runtime:

1. Read `agent-memory/active.md` and `agent-memory/index.md`.
2. Review task result, checks, blockers, user correction, and applied memory.
3. Decide: no lesson, candidate, update metric, promote, revise, or archive.
4. Write weak lessons to `agent-memory/candidates.md`.
5. Track rule performance in `agent-memory/metrics.md`.
6. Promote only with strong evidence.
7. Report the Learning Pass section.
